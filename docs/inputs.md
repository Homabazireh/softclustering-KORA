# Private input checklist

Obtain files from authorized study storage. Never download participant data from a public repository or attach them to public issues.

The runner resolves `load()`, `read.csv()`, `read.csv2()`, and `readRDS()` against the private working directory, then private `inputs/` and `processed/`. Supply required objects under these generic local filenames. Relative paths generated by earlier notebooks are retained under private `work/` so later notebooks can consume them.

| Workflow | Inputs and expected objects |
| --- | --- |
| Clinical notebooks | `clinical.csv`; later/reload sections use `Data.soft.RData` (`Data.soft`), `Data.soft.Metabolic.RData` (`Data.soft.Metabolic`), `assignments_a4.RData` (`assignments_a4`), `as.robust.RData` and `as.robust.Metabolic.RData` (original fitted models). Some sections generate these objects; others reload them. |
| Omics preprocessing | `Proteomics.csv`, `metabolites_p500.csv`, and private `config/metabolomics_exclusions.csv`. No clinical CSV is needed for the preprocessing core. |
| Whole-population omics | `clinical.csv`, matching `Scaled.log.Trans.*.RData` from preprocessing, clinical model/assignment objects. The proteomics notebook also contains an initial reload of `Merged.proteomics.Data.soft.RData`; run that section only when the merged object already exists. |
| MetS regressions | `Merged.proteomics.Data.soft.MetS.RData` (`Merged.proteomics.Data.soft.MetS`) or `Merged.Metabolomics.Data.soft.MetS.RData` (`Merged.Metabolomics.Data.soft.MetS`), and clinical MetS objects/models. |
| Metabolomics group analysis | `Merged.Metabolomics.Data.soft.RData` containing `Merged.Metabolomics.Data.soft`; `Merged.Metabolomics.Data.soft.MetS.RData` containing `Merged.Metabolomics.Data.soft.MetS`. |
| Proteomics group analysis | `Merged.proteomics.Data.soft.RData` containing `Merged.proteomics.Data.soft`; the metabolomics group output under `work/merge_MetS_groups_vf_results/`. |
| `code/clinical/Dive_in_MixedEtiology.Rmd` | Clinical MetS objects/models, both merged MetS omics datasets, significant-protein selection and metabolite regression tables; an optional protein label mapping is referenced. Generate or obtain those tables privately. |
| MOFA2 / DIABLO | Metabolomics grouping output and proteomics grouping CSV generated by the two preceding workflows. |

One older whole-population metabolomics file was named as though it were a MetS-subset file, despite containing `Merged.Metabolomics.Data.soft`. Authorized users should inspect the object name privately, then copy that file locally as `inputs/Merged.Metabolomics.Data.soft.RData`; keep the actual MetS-subset file separate. Never infer equivalence from filenames alone.

Some exploratory sections also reference `DataClean.RData`, unnormalized/control datasets, and stability tables. These are not public inputs. Review the particular section to determine whether to generate them or obtain an existing approved copy. Input matching does not validate participant alignment: verify identifiers and assignment row order before combining datasets.
